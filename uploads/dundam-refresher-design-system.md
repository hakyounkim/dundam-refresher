# 던담 리프레셔 디자인 시스템

이 문서는 던담 리프레셔(dundam-refresher) 프로젝트의 디자인 기준이다.
모든 화면 생성/수정 시 이 규칙을 우선 적용한다.

## 제품 맥락

- 던전앤파이터 캐릭터 데이터를 dundam.xyz에서 일괄 갱신해 보여주는 개인 팬 사이트
- 사용자는 남는 시간에 모바일로 접속하는 게이머. 모바일이 1순위, 데스크톱은 확장
- 도구형 서비스: 소개 문구, 히어로 섹션, 마케팅 카피 없이 첫 화면부터 기능이 보인다

## 컬러

라이트 테마 고정. 토스/당근 계열의 깔끔한 한국 앱 스타일.

| 토큰 | 값 | 용도 |
|---|---|---|
| bg | #FFFFFF | 기본 배경 |
| bg-sub | #F7F8FA | 섹션/입력/카드 배경 |
| text | #1A1D21 | 본문 |
| text-sub | #6B7684 | 보조 텍스트 |
| border | #E5E8EB | 구분선, 카드 테두리 |
| accent | #2D6FF2 | 포인트 (버튼, 활성 탭, 링크, 진행바) |
| accent-bg | #EBF2FE | 포인트 연한 배경 |
| danger | #E5484D | 갱신 실패, 감소 수치 |
| success | #18A05A | 갱신 성공, 증가 수치 |

- 포인트 색은 화면당 accent 하나만 사용
- 아이템/캐릭터 등급 색이 필요하면 던전앤파이터 원작의 등급 색을 그대로 사용. 임의 색 금지

## 타이포그래피

- 폰트: Pretendard Variable (jsdelivr CDN), `word-break: keep-all`
- 스케일: 22px 페이지 제목 / 17px 섹션 제목(600) / 15px 본문 / 13px 보조
- 명성 등 핵심 수치는 크고 굵게 (카드 안에서는 17~20px/700, 상세 화면에서는 28px+)
- 숫자는 전부 `font-variant-numeric: tabular-nums` + 콤마 포맷

## 레이아웃: 한 화면, 두 버전

모바일 레이아웃을 먼저 완성하고, 768px 이상에서 데스크톱 레이아웃으로 재배치한다.
모바일 화면을 그대로 넓히는 것 금지.

### 캐릭터 그리드 (핵심 규칙)

- **데스크톱(768px~): 한 줄에 4개.** 던파는 4인 파티 게임이므로 4의 배수 배치가 기준
- **모바일(~767px): 한 줄에 2개**
- 카드 간격 12~16px, 카드는 그림자 없이 1px border + 12px radius

### 공통

- 모바일: 좌우 패딩 20px, 주 액션(일괄 갱신 등)은 하단 고정 버튼 + safe-area 패딩
- 데스크톱: 최대 폭 1040px 중앙 정렬, 하단 고정 버튼은 상단 영역의 인라인 버튼으로 전환
- 터치 타겟 최소 44px, 버튼 높이 48~52px
- 표가 필요하면 모바일에서는 카드로 변환하거나 첫 컬럼 고정 가로 스크롤

## 상태 표시

**시스템 상태 가시성 (최우선 규칙):** 지금 사이트가 뭘 하고 있는지는 스크롤 없이 항상 보여야 한다.
진행 상태, 완료/실패 알림을 페이지 하단이나 스크롤해야 보이는 위치에 두는 것 금지.

- 일괄 갱신 진행 상태는 **헤더 바로 아래 sticky 바**로 고정: accent 색 진행바 + "12/28 완료" 카운터. 스크롤해도 화면 상단에 따라온다
- 갱신 시작/완료/실패 알림은 화면 상단 토스트로 표시 (3초 후 자동 사라짐, 실패는 수동 닫기)
- 갱신 성공/실패는 카드 단위로도 success/danger 색 점 또는 라벨로 표시 — 전체 상태는 상단에서, 개별 상태는 해당 카드에서
- 갱신 중인 카드는 스켈레톤(회색 블록) 또는 카드 내 진행 표시. 스피너 남발 금지
- 빈 상태/에러는 원인과 다음 행동을 한 줄로: "갱신에 실패했어요. 다시 시도" 버튼

## 금지 목록 (하나라도 위반 시 다시)

- 보라~파랑 그라데이션 배경, 그라데이션 텍스트
- 이모지를 아이콘 대용으로 사용. 아이콘은 인라인 SVG
- 글래스모피즘, 네온 글로우, 다크 게이밍 테마
- 카드마다 box-shadow. 구분은 1px border로
- hover에만 의존하는 인터랙션 (모바일 사용자 기준으로 설계)
- 과장 카피 ("최고의 경험을 만나보세요" 류). 라벨과 숫자만
- 알약형 버튼 radius 남발 (기본 10~12px, 최대 16px)
